# iad-deep-learning

В рамках курса Основы глубинного обучения выполнены работы по следующим темам:
- Полносвязные нейронные сети (файл `fully-connected-neural-networks.ipynb`)
- Классификация изображений (файл `image-classification.ipynb`)
  - Обучение классификатора изображений
- Детекция объектов (файл `detection.ipynb`)
  - Написание архитектуры для детекции, а также 
  - Использование готового библиотечного решения

[Ссылка на страницу курса](http://wiki.cs.hse.ru/Основы_глубинного_обучения/2023)
