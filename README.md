# iad-deep-learning

В рамках курса Основы глубинного обучения выполнены работы по следующим темам:
- Полносвязные нейронные сети (файл `fully-connected-neural-networks.ipynb`)
- Классификация изображений (обучение классификатора изображений) (файл `image-classification.ipynb`)
- Детекция объектов (написание архитектуры для детекции, а также использование готового библиотечного решения) (файл `detection.ipynb`)

[Ссылка на страницу курса](http://wiki.cs.hse.ru/Основы_глубинного_обучения/2023)
